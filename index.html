Projects项目

  • SkillPulse

    Developer开发者

    SkillPulse is a lightweight lifecycle management tool for AI agent skill libraries. It records real execution outcomes through a CLI or Python library and synchronizes observability data from Langfuse and Phoenix. Statistical detection identifies skill degradation and distinguishes environment drift, model changes, task-distribution shifts, and intrinsic skill defects, while a controlled workflow manages candidate fixes, offline replay, canary validation, promotion, and rollback.

    SkillPulse 是一个面向 AI Agent 技能库的轻量级生命周期管理工具，可通过命令行或 Python 库记录真实运行结果，并从 Langfuse、Phoenix 同步可观测数据；它利用统计检测识别技能性能退化，区分环境变化、模型切换、任务分布变化与技能自身缺陷，再通过候选修复、离线回放、灰度验证、晋升或回滚形成完整治理流程。

  • Oh My Clean Data

    Developer开发者

    Oh My Clean Data is a training-data governance platform that unifies format conversion, structural validation, content auditing, issue review, and dataset versioning for CSV, Excel, JSONL, and other source data. A pluggable feedback layer receives per-sample training signals such as loss and entropy, then applies random, loss-priority, or adaptive strategies to select data for the next training round. Model weights remain in the training environment while the platform manages only data, feedback, and selection results, creating a reproducible, traceable, and extensible data-governance–training–selection loop.

    Oh My Clean Data 是一个面向模型训练的数据治理平台，将 CSV、Excel、JSONL 等原始数据的格式转换、结构校验、内容审查、问题复核和数据集版本管理整合为统一流程，并通过可插拔的训练反馈层接收逐样本损失、熵等训练指标，使用随机、损失优先或自适应策略生成下一轮训练数据；模型权重始终保留在训练环境中，平台只管理数据、反馈和选择结果，从而形成可复现、可追溯、可扩展的“数据治理—模型训练—反馈选样”闭环。
